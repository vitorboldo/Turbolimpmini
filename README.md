# TurboLimp Mini

Página de vendas do aspirador portátil sem fio TurboLimp Mini.

## Sobre
Página estática (HTML) com a oferta de 1 unidade por R$ 85,00 e Leve 2 por R$ 97,90, com botão de compra direto para o checkout.

## Como publicar
1. Deixe o arquivo `index.html` na raiz do repositório.
2. Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`.
3. Aguarde 1 a 2 minutos e acesse o link gerado pelo GitHub Pages.

## Como editar
Abra o `index.html` e altere os textos, preços ou links dos botões de compra.
